# 制度汇编网页版 · 使用说明

**文件**：`web/index.html`（单文件 540 KB，双击打开，无需联网、无需服务器）

---

## 一、角色入口

打开页面，最上方是四个身份入口。选中后页面只显示与该角色相关的内容：

| 入口 | 可见内容 | 侧栏条目 |
|---|---|---|
| **学生端** | 行为规范、学业警示、违纪处理、迟到规定、请假调课、升学指导 | 12 项 |
| **家长端** | 学生端 + 特殊照顾、家校沟通 | 14 项 |
| **教师端** | 全部 11 章 + 下卷条目库 + 交叉索引 | 81 项 |
| **管理者** | 全部 + 待确认事项、剩余缺口、来源统计 | 84 项 |

- 每张卡片列了 4–5 条该角色最常问的问题，点击直达
- 角色记在浏览器本地，下次打开仍生效
- 直达链接：`index.html?role=s`（学生）/ `p`（家长）/ `t`（教师）/ `a`（管理者）

## 二、本次 UI 重构要点

### 修复的问题

| 问题 | 原因 | 处理 |
|---|---|---|
| **流程图出现黑色框、白字** | `pre` 用了深色底 `#0f2238`，与整体浅色体系冲突 | 改为浅灰底 + 左蓝色描边 + 深色字，与正文同一色系 |
| **`##### 一、黄色警示` 原样显示** | 解析器只支持 4 级标题，漏掉 13 个五级标题 | 扩展到 6 级，并补齐 h5/h6 样式 |
| **手机上角色卡被裁切** | 栅格按 2 列排布超出视口 | ≤760px 强制单列 + 顶栏 `min-width:0` |
| **元信息四块分散** | 每条 `blockquote` 独立成卡片 | 相邻引用块自动合并为一张卡片，内部用细线分隔 |

### 视觉规范统一

- **单一色板**：主色 `#1f3a5f`（深蓝）、次色 `#2c5588`、强调色仅用于语义提示
- **语义化提示块**：
  - ⚠️ 警告 → 琥珀色（`#fdf6e9` + 琥珀左边框）
  - ❌ 禁止 → 红色（`#fcf2f0` + 红左边框）
  - 普通说明 → 浅蓝（`#eaf0f7`）
- **标题层级**：h1 24px → h2 18.5px → h3 16px → h4 14.5px → h5 13.8px，h2/h3 用左竖线 + 虚线下划线区分
- **表格**：13px、行高 1.55、斑马纹、悬停高亮、横向滚动，比原先更紧凑
- **侧栏**：条目 12.8px、编标题带蓝色竖条标记、激活项为深蓝实心

## 三、阅读体验

### 密度切换

右上角「**紧凑 / 舒适**」按钮：

| 模式 | 正文字号 | 行高 | 表格 |
|---|---|---|---|
| 舒适（默认） | 15.5px | 1.72 | 13px / 内边距 7×10 |
| 紧凑 | 14.5px | 1.58 | 12.3px / 内边距 5×8 |

同样屏宽下，紧凑模式一屏约多显示 **25–30%** 内容。偏好会记住。
直达：`index.html?density=compact`

### 阅读进度条

页面顶部有 2.5px 蓝色进度条，随滚动实时变化，长文档里随时知道看到哪了。

### 锚点与跳转

- 侧栏 84 个导航项，全部锚点有效（校验 0 失效）
- 滚动自动高亮当前章节 + 顶部面包屑
- 附录 A 交叉索引 22 处可点击（上卷章 ↔ 下卷小节）

## 四、搜索

- 左上角搜索框，**189 个标题**全部建索引
- 输入即时出结果，带上下文摘要与关键词高亮
- **自动跟随角色**：学生搜「监考」不会搜出教师的考务管理章节
- `Ctrl + K` 聚焦，`Esc` 关闭

---

## 五、响应式与打印

| 屏幕 | 表现 |
|---|---|
| ≥960px | 左侧固定目录 300px，正文最大 900px |
| 760–960px | 目录收起为按钮 |
| ≤760px | 角色卡单列，正文全宽，表格横向滚动 |

**打印**：隐藏侧栏/角色卡/按钮，强制显示全部内容（不受角色过滤影响），每卷另起一页，表格与流程图避免跨页断裂。

## 六、更新方式

```powershell
python merge-final.py        # 合并 markdown
python build-web-roles.py    # 生成 index.html
```

调整角色可见范围：改 `build-web-roles.py` 顶部 `CH_ROLES`（章 → 角色）与 `PART_ROLES`（编 → 角色）。角色代号：`s` 学生 / `p` 家长 / `t` 教师 / `a` 管理者。

---

## 七、已知限制

- 搜索为**子串匹配**（「监考老师」可搜到，「监考 老师」搜不到）
- 角色过滤按**章节**粒度，同一章内不再细分
- 流程图是等宽文本排版，窄屏下需横向滚动
- 打印不带页码（需要页码请在 Word 版处理）
