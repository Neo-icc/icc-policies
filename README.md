# ICC 学校制度汇编

石家庄外国语学校国际课程中心 · 2026 学年制度汇编（草案）

本仓库把散落在会议记录中的学校规定，整理成**可执行、可追溯、可按角色分发**的制度文本。

---

## 在线浏览

打开 [`index.html`](index.html) 即可（单文件，无需服务器、无需联网）。

也可以直接访问：`https://<你的用户名>.gitee.io/icc-policies/`（需在 Gitee 仓库设置里开启 Pages）

### 角色入口

页面顶部可选择身份，选中后只显示与该角色相关的内容：

| 角色 | 可见内容 |
|---|---|
| **学生端** | 行为规范、学业警示、违纪处理、迟到规定、请假调课、升学指导 |
| **家长端** | 学生端 + 特殊照顾、家校沟通 |
| **教师端** | 全部 11 章制度 |
| **管理者** | 全部 + 待确认事项、剩余缺口、来源统计 |

其他功能：全文搜索（`Ctrl+K`）、目录自动高亮、阅读进度条、紧凑/舒适密度切换、打印样式。

## 内容结构

共 **11 份制度 + 3 个附录**，按适用对象分五编：

| 编 | 制度 |
|---|---|
| 第一编 学生行为与纪律 | 学生日常行为规范 · 学业警示制度 · 学生违纪处理与教育惩戒办法 |
| 第二编 考试与考务 | 考试与成绩管理办法 · 考试入场与迟到处理规定 · 特殊照顾申请判定标准 |
| 第三编 教师管理 | 教师发展与考核办法 · 请假、调课与代课管理办法 |
| 第四编 家校与升学 | 家校沟通规范 · 升学指导工作规范 |
| 第五编 治理与技术支持 | AI 使用与数据治理规范 |

**附录**：待确认事项清单（10 项）· 剩余缺口（3 项）· 来源覆盖与统计

## 使用须知

⚠️ **本汇编为草案，不是生效文件。**

按《中小学教育惩戒规则（试行）》第 5、6 条，校规校纪须经
**征求意见 → 家长委员会/教代会讨论 → 校长办公会审议 → 公布 → 报教育部门备案**
后方可施行；**未经公布的校规校纪不得施行**。

文中的 `【待确认】`「建议值」需学校确认后才能作为执行依据。
条文末尾的「（依据：xxxx-xx-xx 会议）」标注了具体出处，便于回溯核对。

## 文档修订

制度内容以 Markdown 为源，网页由脚本生成。修改流程：

1. 编辑 `docs/ICC制度汇编-公开版.md`
2. 用生成器输出 HTML（另见内部仓库脚本）
3. 提交更新

如需直接编辑 `index.html`，搜索定位对应段落即可，但下次生成会覆盖。
